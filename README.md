# Daily Operations MIS & Dashboard

## Project Overview
This beginner-friendly Excel project tracks field activities, turnaround time (TAT), checklist completion, and operational performance. It is designed as a fresher-level portfolio project based on common MIS Executive / Operations Reporting responsibilities.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- COUNTIF / COUNTIFS
- XLOOKUP and VLOOKUP
- Conditional Formatting
- Charts and dashboard KPIs
- Pivot Table practice (instructions included)

## Workbook Sheets
1. **Read Me** – quick instructions and project overview.
2. **Activity Data** – 120 fictional activity records with dates, region, assigned staff, target/actual TAT, status, and checklist completion.
3. **Dashboard** – master summary KPIs and charts by status and region.
4. **FMS Summary** – field activity, status, TAT, and checklist overview.
5. **Checklist Summary** – checklist completion counts and compliance rate.
6. **MIS Summary** – monthly activity counts and operational summary.
7. **Lookup Practice** – sample XLOOKUP and VLOOKUP formulas to retrieve activity details.
